# 국립부경대학교 사회복지 소개 홈페이지

별도 설치나 빌드 없이 사용할 수 있는 HTML/CSS/JavaScript 홈페이지입니다.

## 내 컴퓨터에서 열기

`index.html`을 더블 클릭하세요. Chrome 또는 Edge에서 열 수 있습니다. 사이트와 사진은 로컬에서 열립니다. 영상 시청과 외부 자료를 보려면 인터넷 연결이 필요합니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. **Add file → Upload files**에서 이 폴더 안의 파일 전체를 올립니다. `index.html`, `styles.css`, `content.js`, `app.js`가 저장소 최상위에 있어야 합니다. 폴더 자체를 한 단계 더 넣지 마세요.
3. **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch는 **main**, Folder는 **/(root)**로 지정하고 **Save**를 누릅니다.
5. 게시가 끝나면 Pages 화면에 표시되는 주소로 접속합니다.

예: `https://사용자이름.github.io/저장소이름/`

이 패키지에는 상대 경로만 사용하므로 GitHub Pages의 저장소 주소 아래에서도 동작합니다. 자동 수집 API, 서버, 비밀키가 필요하지 않습니다.

## 파일 안내

- `index.html`: 홈페이지 첫 화면, 메뉴, 작업 표시줄
- `styles.css`: 색상, 글자, 창과 모바일 디자인
- `content.js`: 교수, 교육과정 소개, 학과 성과, 다솜모임, 복지정보 링크
- `app.js`: 창 열기/닫기/최소화/최대화/이동 및 작업 표시줄
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 제공
- `assets/`: 교수 사진 5장과 다솜 영상 썸네일 3장
- `SOURCES.md`: 확인한 출처와 자료 범위

## 내용 수정

교수 소개와 학과 성과는 `content.js`의 `DEPARTMENT`를 수정하세요. 각 창의 글은 같은 파일의 `CONTENT`에서 수정합니다. 메인 화면 문구는 `index.html`에서 수정합니다. 바꾼 파일을 GitHub에 다시 업로드하면 게시 내용도 갱신됩니다.

## 창 사용법

- 메뉴나 바탕화면 아이콘을 클릭하면 소개 창이 열립니다.
- 제목 표시줄을 드래그하면 데스크톱에서 창을 이동할 수 있습니다.
- `−`는 최소화, `□`는 최대화/복원, `×`는 닫기입니다.
- 작업 표시줄에서 최소화한 창을 다시 열 수 있습니다.
- `Escape`는 현재 선택한 창을 닫습니다.
- `캠퍼스`와 `바탕화면` 버튼으로 모든 창을 최소화합니다.
- 모바일에서는 창을 화면에 맞게 표시하고 내부 콘텐츠를 스크롤합니다.

## 자료와 운영

자료 확인일: 2026-10-01. 정보는 자동 갱신되지 않습니다. 공식 운영 안내가 바뀌면 `content.js`도 갱신해주세요.

공식 학과 고유 정보와 확인된 소식을 사용했습니다. 취업률, 실습 시간, 입학 요건, 모집 일정 등 미확인 숫자는 넣지 않았습니다. 다솜 소개는 공개 영상 제목과 회차에 근거하며, 참여 대상과 운영 규정은 확정하지 않았습니다. 인스타그램은 공개 계정 확인 후 추가 소식으로 연결합니다.

교수 사진 및 영상 썸네일은 원출처에서 확보하여 `assets/`에 함께 저장했습니다. 이미지의 권리는 원출처에 있습니다. 출처는 `SOURCES.md`와 `assets/CREDITS.md`에 정리했습니다.

Awwwards의 밝은 회색 배경, 굵은 대형 타이포그래피, 검정 패널과 편집형 구성을 참고했습니다. 콘텐츠와 로고는 이 사이트에 맞게 새로 구성했습니다. 독립적인 학과 소개 사이트이며 공식 홈페이지를 대체하지 않습니다.
